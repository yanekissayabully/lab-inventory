# Lab Inventory

Task 4 — Async React: Effects & API. Учёт оборудования небольшой лаборатории поверх
симулированного асинхронного API (Promise, случайные задержки, ошибки, `localStorage`).

**Live:** https://yanekissayabully.github.io/lab-inventory/

## Что умеет

- Загрузка списка в `useEffect`, фильтр по статусу, кнопка **Reload**.
- Состояния loading / error / empty / success для списка и для деталей, повтор по кнопке.
- Выбор элемента → асинхронная загрузка полной карточки (9 полей: категория, серийный номер,
  местоположение, ответственный, дата покупки, дата последнего обслуживания, стоимость,
  заметки, статус).
- Create / Edit / Remove (удаление с подтверждением).
- Действие над выбранным элементом через API: выдать (check out), вернуть, отправить на
  обслуживание, завершить обслуживание.
- Панель **Network simulator** — задержки (быстро / обычно / медленно) и доля ошибок
  (0 / 5 / 30 %), чтобы удобно показывать гонки и ошибки.

## Стек

- Next.js (App Router, статический экспорт) + TypeScript
- CSS Modules, без UI-библиотек
- Из хуков только `useState` и `useEffect`, без кастомных хуков, дебаунса и библиотек
  для запросов

## Структура

- `lib/api/fakeApi.ts` — «сервер»: задержки, ошибки, `AbortSignal`, чтение/запись
  `localStorage`. Единственное место, которое обращается к `localStorage`.
- `lib/api/settings.ts` — ключ хранилища и настройки симуляции.
- `lib/api/seed.ts` — начальные данные.
- `lib/types.ts`, `lib/items.ts`, `lib/status.ts` — типы, чистые хелперы, правила смены статуса.
- `components/Inventory.tsx` — весь state и все эффекты.
- `components/ItemList.tsx`, `ItemDetails.tsx`, `ItemForm.tsx`, `StatusControls.tsx`,
  `ItemActions.tsx`, `Simulator.tsx` — презентационные компоненты.

## Как избегаются гонки и устаревшие замыкания

- Каждый эффект загрузки создаёт `AbortController` и флаг `ignore`; cleanup выставляет оба.
  Ответ на предыдущий запрос либо отменяется, либо игнорируется.
- Обработчики мутаций берут `id` в момент клика и применяют ответ к списку и деталям
  функциональными обновлениями, сверяя `id`.
- Пока идёт мутация, остальные мутирующие кнопки заблокированы; во время отправки формы
  заблокирован и выбор элемента.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # статический экспорт в out/
```

Данные лежат в `localStorage` под ключом `lab-inventory-v1`; чтобы сбросить к начальным,
удалите эту запись.

## Деплой
